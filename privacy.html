개인정보처리방침

시행일: 2026년 11월 25일

1. 무엇을 하나

«흐름타기업로드»는 유튜브 채널 «흐름타기» 운영자가 자기 PC에서 실행하는 개인용 도구로, YouTube Data API를 통해 운영자 본인이 만든 영상을 운영자 본인의 채널에 업로드합니다.

2. 다루는 정보

  • Google OAuth 로그인 토큰: 영상 업로드와 채널 이름 확인에만 쓰며, 운영자 PC에만 저장합니다.
  • 업로드할 영상 파일과 제목·설명·태그: 운영자가 직접 만든 것이며 유튜브에만 전송합니다.

3. 제3자 제공

어떤 정보도 판매하거나 제3자와 공유하지 않습니다. 다른 사용자의 정보는 수집하지 않습니다.

4. 권한 철회

Google 계정 설정(https://myaccount.google.com/permissions)에서 언제든 이 도구의 접근 권한을 없앨 수 있습니다.

5. 문의

유튜브 채널 «흐름타기»로 문의해 주십시오.

이 도구의 Google API 사용은 YouTube API 서비스 약관과 Google 개인정보처리방침(https://policies.google.com/privacy)을 따릅니다.
